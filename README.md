Standard Laptop Procurement Automation

Project Description

This project automates the standard laptop procurement process using ServiceNow Flow Designer.

Technologies Used

- ServiceNow
- Flow Designer
- Service Catalog
- Approval Process

Project Objectives

- Automate laptop request approval.
- Create Catalog Tasks automatically.
- Assign tasks to the Hardware assignment group.
- Reduce manual work and human errors.

Project Outcome
